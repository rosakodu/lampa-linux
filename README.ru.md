# lampa-linux

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md)

Автономное **AppImage** приложение **Lampa** для Linux со встроенным **TorrServer** и кастомным транскодером **WebM VP8 + Opus** для бесшовного воспроизведения торрентов во встроенном плеере Lampa.

## 📋 Возможности

- **Локальный Lampa**: Раздает статические файлы Lampa на порту 8300.
- **Встроенный TorrServer**: Автоматически запускает встроенный TorrServer для локального стриминга торрентов на порту 8090.
- **Транскодирование WebM VP8 + Opus**: Фоновый движок транскодирования на базе FFmpeg преобразует неподдерживаемые в Linux/Chromium форматы видео (HEVC/H.265, AV1) и аудио (AC-3, DTS, AAC) в формат WebM (VP8 + Opus) на лету. Это позволяет воспроизводить любые фильмы прямо во встроенном плеере Lampa без сторонних внешних плееров.
- **Самодостаточный AppImage**: Запуск в один клик без необходимости установки системных зависимостей, Node.js или Python.
- **Чистая установка**: Поставляется без предустановленных плагинов, парсеров и сторонних ресурсов. Настраивайте всё под себя.

## 📦 Рекомендации по настройке

Lampa требует ручного добавления источников контента. Мы рекомендуем использовать следующие ресурсы:

- **Адрес TorrServer**: Уже настроен в Lampa по умолчанию как `http://127.0.0.1:8090`.
- **Поиск по торрентам**: Рекомендуем использовать популярный парсер [JacRed](https://jacred.ru/) (`https://jacred.ru/`).
- **Полезные плагины**:
  - **TMDB / Онлайн просмотр**: Репозиторий плагинов [nb557 Lampa Plugins](https://github.com/nb557/lampa-plugins) или плагин `https://plugin.rootu.top/tmdb.js`.
  - **Синхронизация CUB**: Сервис [CUB.red](http://cub.red/) для хранения закладок.
  - **Плагин поиска Jackett**: Доступен через сообщество [Bylampa](https://github.com/bylampa/bylampa.github.io).

## 📥 Установка и запуск

1. Скачайте `Lampa-1.0.0.AppImage` со страницы [Releases](https://github.com/rosakodu/lampa-linux/releases).
2. Сделайте файл исполняемым:
   ```bash
   chmod +x Lampa-1.0.0.AppImage
   ```
3. Запустите:
   ```bash
   ./Lampa-1.0.0.AppImage
   ```

## 🚀 Использование

1. Запустите `Lampa-1.0.0.AppImage`.
2. В настройках Lampa пропишите адрес парсера JacRed и добавьте необходимые плагины.
3. Откройте любой фильм, выберите торрент-файл и нажмите **Play**.
4. Видео автоматически будет воспроизводиться во встроенном плеере Lampa.
